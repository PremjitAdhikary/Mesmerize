Documentation

This is a simplified version of Logo. It has the most basic commands with which one can do some art.

Code Editor

All your code goes into the Code Editor. Separate out commands by space and/or line-break. The output of your code is rendered into the Viewport on the Left. This is in real-time which means as and when you write code, the Viewport will reflect the output.

Turtle Graphics

The commands you write in the Code Editor, is interpreted and rendered by Turtle Graphics Engine. The Viewport is 640 × 480. The turtle is right at the center pointing up. Based on the commands, the turtle moves and renders lines.

All the information that you need to come up with your awesome art.

  • To move the turtle forward by 60 pixels and draw a line on its path:

    fd 60

    Run

  • To move the turtle backward by 50 pixels and draw a line on its path:

    bk 50

    Run

  • To turn clockwise by 90°

    rt 90

    Run

  • To turn anti-clockwise by 30°

    lt 30

    Run

  • To clear the screen

    cs

  • Pen Up and Pen Down Command lets the turlte know whether to leave ink when it moves around. By default, Pen Down is enabled.

    pu // pen up pd // pen down

    Run the example to see a dashed line rendered using the commands.

    Run

  • Show Turtle and Hide Turtle does exactly what it advertises. By default, Show Turtle is enabled.

    st // show turtle ht // hide turtle

    Run the example to see the turtle being hidden.

    Run

  • The repeat command allows you to, well, repeat commands n number of times.

    repeat 4 [fd 90 rt 90] // draws a square repeat 360 [fd 1 rt 1] // draws a circle

    Run the example to draw a square and a circle.

    Run

  • The home command is like a reset for the turtle to its origin position facing up without drawing a line from its previous position.

    home

    Run the example to see the turtle return to home after drawing something.

    Run

  • The setxy command is similar to home. Only instead of origin, you can specify (x,y) where you want the turtle to end up.

    setxy 200 -150

    Run the example to see the turtle go to (200, -150) after drawing something.

    Run

One day I was goofing around on this and came up with a cool font to write my name. What followed next was me, figuring out logo code to render all the letters of the English alphabet!

Now that was done, I wanted to somehow incorporate those into this program so that I don't have to keep re-writing the same (DRY). The first thought was to incorporate the logic into the interpreter itself. Basically some sort of command to work with.

out premjit

But the more I worked with this approach, the lesser it made sense! So a different approach. I took the idea of code snippets...

Instead of building the logic into the interpreter, I made it a feature of the editor to generate the required code to feed into the interpreter.

#premjit#

Try

Any string in between the hashes is picked up, replaced with the appropriate set of logo commands for the letters and then rendered out on the viewport! Note that this is not a text editor and it only recognizes English letters (and a space) all on one line.

Again, this is not a logo language construct, but a (very) limited feature added for fun.
