Added keyboard service to mobile which will be used for some future phone-apps that I have in pipeline. This is a very basic keyboard, doesn't support all the keys (usually found on standard keyboards), but enough to carry on a conversation.

Input is accepted through mouse clicks and actual keyboard too. The keyboard inputs are filtered to only accept the repective keys on the virtual keyboard displayed on M-Phone.

Apps built using NEW keyboard feature

Allows user to write transient notes.

Usage:
  • Click anywhere on the notes area to start typing on the new keyboard.
  • Once done, click the button next to the text box to update the notes area with your input.
  • Click on existing sentence to open the sentence on the keyboard and edit.
  • Use backspace to delete characters from the end. Unfortunately you cannot position the cursor.
  • Use enter button to introduce a new line.
  • The New button in the bottom right corner deletes current note and allows user to start again.

This is a fun mini story composer. Users answer 3 to 4 questions which is then used to generate a mini story. Think form fill-up.

Usage:
  • Once answered, click the button next to the text box to update the answer in the data collection area.
  • Use backspace to delete characters from the end. Unfortunately you cannot position the cursor.
  • Using enter button just introduces a space.
  • Once all answers are entered, the story is generated and displayed.
  • The New button in the bottom right corner starts a new form for another story.
