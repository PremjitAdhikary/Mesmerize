More of testing/demo page for Octree.

The idea is same as a Quadtree with an additional dimension. Instead of 4 children, each tree can have 8 children.

Controls

  • The buttons add elements randomly over the 3D space enclosed by the root tree. Child trees get created as and when elements are added.
  • The sliders manipulate the query box across x, y and z axes.
  • The elements in the query box are hilighted in green.
  • Using mouse on the Viewport allows to control the camera. Click and drag to move Camera. Hold Control, Clik and drag to pan Camera. Scroll to Zoom In/Out.
