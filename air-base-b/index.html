I saw the movie Bhuj: The Pride of India recently. Hmmm... a toned down version as a game can be made.

List of libraries used here:

  • p5.js SceneManager - To switch among games and menus.
  • p5.scribble.js - To have a sketchy look for the game artwork.
  • p5.collide2D - To have collision detection.
  • Tone JS - For audio.

While I loved the graphics generated by Scribble, it really did a number on the performance. So I had to keep an alternative. By default the alternative version (Blocks) runs. Flip it to Pencil or Sketch and try them out. If the performance is not affected, enjoy some scribblish kinda game artwork.
