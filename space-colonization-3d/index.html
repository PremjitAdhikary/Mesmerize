The 2D version of Space Colonization was covered in a previous segment. The same algorithm is implemented here albeit in 3D.

Controls

  • Select one of the trees on the left. On selection attractors are generated and distributed in a determined 3D space.
  • On click of Generate Tree, the Space Colonization algorithm starts running and places nodes for the branches to connect to.
  • On completion of the algorithm, Show Tree/Nodes toggle is enabled. This allows you to toggle the view to display the rendered tree or the nodes.
  • When tree view is on, you can toggle to check out a texture rendered version too.
  • Using mouse on the Viewport allows to control the camera. Click and drag to move Camera. Hold Control, Click and drag to pan Camera. Scroll to Zoom In/Out.
  • If Viewport is in focus, the keyboard can also be used. Use Arrow keys to move Camera. Control + Arrow keys to pan Camera. Alt + Up/Down Arrow keys to Zoom In/Out.

The Attractors

How are they distributed?

Easiest of all. Spread the attractors over a rectangular parallelepiped. Just random x, y, z over a range and offset y by some distance to lift the attractors above ground.

Here attractors are spread out in a sphere. Gives much natural tree-ish look. The sphere is squished a bit along y-axis (and lifted up).

Same idea as Generic, but the attractors are pushed towards the face of the shape.

Instead of a sphere, here a cone is used as an envelope.

Instead of a sphere, here a Hemisphere is used as an envelope. This is re-imagining the 2D version in 3D.

Multiple envelopes placed at random locations to come up with a natural looking tree.


Octree Usage

In the 2D version I used quadtree to make this algorithm more performant. In this version, I use Octree for the same purpose - efficiently search for the nodes to be affected by the attractors but in 3D space.
