Not going to explain Sudoku. This is to show how algorithms work on a typical Sudoku puzzle.

Controls

  • To set up a puzzle, click any of the buttons to randomly pick a puzzle (of that difficulty) and ready the board.
    • Easy puzzles have 30+ cells prefilled.
    • Normal puzzles have 25+ cells prefilled.
    • Hard puzzles have 16 to 17 cells prefilled.
    • Brute Force Killers are puzzles specifically designed to stump computer algorithms which try to solve Sudoku puzzles using Brute Force algorithms.
  • Click on Solve Puzzle to run the selected Algorithm. While running, a progress bar is displayed at the bottom to indicate how much is left to solve the puzzle.
  • Speed at which the algorithm visualization runs.

Algorithms

Uses a DFS approach to solve the puzzle.

Basically Brute Force where every empty cell is visited and digits filled sequentially. If the number is found to be not valid, backtrack to the last valid cell and start again.

An improvement over the Backtracking algorithm

In the step to find an unassigned cell, here, we check each of the open squares (i, j) to see how many number candidates remain for each - i.e. have not already been used in either row i, column j, or the sector containing (i, j). We pick the square with the fewest number of candidates.

This helps trim the possibilities for other open squares. If the most constrained square has two possibilities, we have a 1/2 probability of guessing right the first time, as opposed to a (1/9)th probability for a completely unconstrained square.
